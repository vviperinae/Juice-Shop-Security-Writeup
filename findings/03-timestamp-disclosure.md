# ୨୧ Timestamp Disclosure ୨୧

## ⑅ ‧₊˚ ↬ *Overview*
ʚɞ **Severity:** Low<br>
ʚɞ **Endpoint:** Various API Responses<br>
ʚɞ **Category:** Information Exposure

<br>

## ⑅ ‧₊˚ ↬ *Description & Exploitation*
While passively scanning the HTTP traffic generated by navigating the Juice Shop, OWASP ZAP flagged multiple instances of "Timestamp Disclosure". 

By reviewing the raw HTTP history, we observe that the backend API is frequently exposing raw Unix timestamps and internal system time data within its JSON responses:

```json
HTTP/1.1 200 OK
Content-Type: application/json

{
  "status": "success",
  "data": {
    "id": 1,
    "role": "admin",
    "updatedAt": "2026-09-26T15:17:52.000Z"
  }
}
```

While not a direct vector for exploitation, leaking internal system time assists an attacker in the reconnaissance phase. It allows them to accurately fingerprint the backend server time, calculate server uptime, or potentially synchronize time-based attacks against pseudo-random number generators or cryptographic tokens.

<br>

## ⑅ ‧₊˚ ↬ *Remediation*
Strip internal timestamps from API responses unless they are strictly required for front-end rendering or client-side functionality.
